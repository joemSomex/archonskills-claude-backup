# Universal Visual Style Prompt

```text
Create an original [DELIVERABLE TYPE] for [SUBJECT / PROJECT] using a [HIGH-LEVEL DESIGN SYSTEM] built specifically from the subject’s function, structure, behavior, or meaning.

COMPOSITION:
[Negative-space strategy, information density, focal hierarchy, cropping, foreground/midground/background planes.]

SUBJECT TREATMENT:
[How the subject appears across compatible states: photograph, silhouette, physical render, wireframe, diagram, section, point cloud, or material detail.]

GRAPHIC SYSTEM:
[Project-specific grids, arcs, rails, measurements, labels, exploded views, cross-sections, status elements, and leader lines. State what each family communicates.]

COLOR:
Use [DARK BASE], [DOMINANT SATURATED HUE], [TECHNICAL ACCENT], [PALE NEUTRAL], and [SPARSE WARNING COLOR]. Each color represents a defined state or physical source. Use an original palette unrelated to the reference property.

TYPOGRAPHY:
[Original type categories and hierarchy.] Combine [large display behavior] with [small annotation behavior]. Generate only project-specific labels, codes, measurements, and wording.

TEXTURE:
[Controlled scanline, dither, grain, raster, print, material, or registration behavior.] Apply artifacts only where they communicate state change, depth, or medium.

LIGHT AND MATERIAL:
[Lighting direction and purpose, surface response, reflection, translucency, bloom, and physical production treatment.]

DEPTH:
[Sharp and soft planes, graphic/subject intersection, atmospheric or material layering.]

ORIGINALITY LOCK:
Create a new visual grammar specific to [PROJECT]. Do not imitate any recognizable logo, emblem, character, silhouette, color combination, typography, interface, glyph, diagram, wording, composition, or transition sequence from an existing property. Preserve only broad principles of [TRANSFERABLE PRINCIPLES].

OUTPUT:
[Dimensions, orientation, medium, required content, practical use, and file constraints.]
```

## Motion Add-On

```text
MOTION:
Reveal the design through [ORIGINAL PROGRESSION]. Assemble elements in functional layers, alternate sparse and dense states, and use controlled artifacting only at meaningful transitions. Keep underlying object and camera motion continuous. Labels appear only after their related object becomes readable. Avoid copied interface transitions, random glitch overlays, and generic corporate morphing.
```

## Short Style Suffix

```text
Apply an original [HIGH-LEVEL AESTHETIC] with [COMPOSITION LOGIC], [PALETTE ROLES], [TYPOGRAPHY HIERARCHY], [GEOMETRIC SYSTEM], [SUBJECT TREATMENT], and [CONTROLLED TEXTURE]. Derive every motif and label from the new subject. Avoid recognizable assets, terminology, symbols, layouts, palettes, and transition sequences from existing media.
```
