# Originality Boundary

Use this table when deciding what can transfer from a visual reference.

| Usually transferable | Usually iconic; rebuild or exclude |
|---|---|
| Negative-space ratio and density contrast | Logos, emblems, mascots, named characters |
| Asymmetric modular composition | Exact module arrangement or signature layout |
| Palette roles such as base/accent/warning | Exact signature color combination and proportions |
| Typography hierarchy and scale contrast | Proprietary typeface, wordmark, distinctive glyph treatment |
| Broad geometry families: grid, arc, section, rail | A unique recurring symbol or exact circular device |
| Integration of diagram, photo, 3D, and wireframe | Specific character/equipment silhouettes |
| Controlled scanline, dither, or misregistration logic | Exact glitch pattern or transition sequence |
| Reveal structure: signal → system → subject | A branded boot/reboot narrative or proprietary terminology |
| Source-bound labels and measurements | Copied labels, codes, slogans, and UI text |
| Alternation of sparse and dense states | Exact shot order and recognizable hero frames |

## Decision Test

Ask:

1. Would a fan recognize the source from this element alone?
2. Is it functional grammar or a branded/signature asset?
3. Can the element be regenerated from the new subject’s real structure?
4. Has the palette, wording, motif, and sequence changed materially?
5. Does the final prompt still work if the source is never named?

If recognition remains likely, abstract one level higher or remove the element.

## Evidence Categories

Document source observations under:

- Composition and negative space
- Palette roles
- Typography hierarchy
- Geometry and modules
- Subject/image treatment
- Texture and controlled artifacts
- Lighting and materials
- Depth and layering
- Motion and transitions
- Pacing and rhythm
- Audio, only when verified

End with two lists: `Transfer` and `Do not copy`.
