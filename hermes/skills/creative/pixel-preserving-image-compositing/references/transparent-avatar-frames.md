# Transparent avatar-frame concepts

Use when designing a batch of new profile-frame concepts from brand, material or effect references. This is design generation, not a pixel-locked edit of an existing frame.

1. **Assign reference roles before prompting.** Identify which attachments supply construction, palette, or surface texture. If the user likes a prior frame, use it only as a style/quality cue unless they ask to keep its geometry. For mineral, fire or rock macros, transfer only the surface and narrow embedded light; forbid copied rock chunks, flames, smoke and full-background effects. Choose a coherent material family but reserve visibly different outer architectures before generation. For strict tier progression, vary broad plate/rim structure and overall width; for a concept slate, prioritize independent sweeping, segmented, orbit, iris and openwork silhouettes over uniformity.
2. **Choose geometry workflow.** When the outer silhouette must be perfectly circular, render a continuous annulus deterministically at oversampled resolution with all inlays clipped to its alpha. When varied outer silhouettes are allowed, make each reference-driven image independently, always keeping a round clear area large enough for a profile picture. Use the original texture reference on every call; do not make a later variation from another generated frame. Prompt the image model for an evenly lit, vivid single-color chroma key in the entire aperture, exterior and true gaps. Explicitly forbid text, logos, portraits, black fills, checkerboards and cast shadows, since any of these can survive keying as false frame pieces.
3. **Extract true RGBA.** Sample the actual background color before setting a green-dominance threshold; generated 'flat green' often varies slightly by position. Convert green dominance to a feathered alpha, then replace RGB in partial-alpha edge pixels with nearby opaque surface color (for example, normalized Gaussian blur of RGB multiplied by an opaque-core mask). Set RGB to zero where alpha is zero and suppress residual saturated green edge pixels. Resize with antialiasing to the requested canvas. If a frame runs close to the image edge, crop its foreground bounding box and scale it *uniformly* into a centered padded transparent canvas; never independently stretch axes.
4. **Verify every file and the batch.** Programmatically assert PNG dimensions/mode, alpha zero at center and canvas edges, full-object padding, alpha extrema and a clearly open center. Cast radial rays from the center to the first nontransparent pixel and require a minimum photo-safe radius; this detects spokes or model-made decorations intruding into the avatar area when the center pixel alone is clear. Check connected components for detached debris, saturated green fringe, distinct hashes and the requested count. Hashes prove different files, not different designs; compare macro silhouettes at avatar thumbnail size when visual review is requested. Keep contact sheets internal and deliver standalone PNGs separately.
