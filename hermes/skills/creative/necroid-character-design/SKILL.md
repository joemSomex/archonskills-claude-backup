# Necroid角色设计

## When to Use / 适用范围

用户要求按多张参考图设计新的 Necroid 角色、批量生成角色图，或修订同一工作流时使用。不要把此 skill 当成既有角色的固定外貌设定；每次都以当前图和当前明确要求为准。用户只要求修改 skill 时，不生成图片。

## 用户原始要求（保留原文）

我会提供几张参考图。图一只作为面部参考：请先提取其中可辨认的主要面部特征，并以此设计新角色的面部；不要擅自补上图一没有的五官。除非我另有要求，眼睛设为红色。

图二及后续图片只作为服装或机甲的美术设计参考。请借鉴其材质、结构和设计语言，创作全新角色，不要直接复制参考图中的整套服装或机甲。

请生成八张彼此独立设计的角色图片，每张都是一名角色的正面全身全景，不是同一设计的轻微换色或换甲片。服装和机甲以黑色为主，红色点缀；脸部及身体其他露出的肌肤，局部呈现不规则的红色大理石状裂纹，不要覆盖全部肌肤。

每张均使用白色无缝棚拍背景、写实质感和2:3竖版构图。角色从头顶到双脚完整入画，四周留有适当空间。最终交付八张独立图片，不要合成一张拼图。如我对面部、眼睛、服装、机甲或其他部位另有具体要求，以该次要求为准。

## 面部辨识度与本轮物种要求

- 仅在人类角色请求下，以**写实真人肖像**为面部标准：保留可信的人类头骨与五官比例、自然肤质和毛孔、真实光影与表情。若用户明确指定“非人类机甲怪物”，该要求覆盖人脸默认；可把图一面部覆纹、遮挡与材质转译成原创非人头颅，不必补人类鼻唇，也不要把真人藏在头盔里。
- 先观察图一能辨认的面部轮廓、骨相、眼/鼻/口的存在与形态、发际线、发型、肤质及可见覆盖物；从这些**实际可见**的特征提炼每名新角色的识别点，避免八张共用同一张泛化的脸。图一没有露出的五官不得凭空补齐；遮挡或缺失是设计事实。
- “可辨识度”来自可见特征的比例与组合、面部轮廓、发型和表情差异，不通过虚构缺失五官、照搬图一人物身份或把红色眼睛放到本来没有眼睛的区域来实现。仅在眼睛实际存在、可见且本轮未另行指定时应用红眼默认。
- 红色大理石裂纹仅落在露出的肌肤局部，保留真实皮肤阅读与面部识别点；不要让裂纹替代五官或覆盖整个脸。若图一是面具且用户要求重新设计，借面部遮挡、眼窗和材料语言，不照搬原面具配色、镶边、口部或轮廓；若要求面具裂缝，逐张确认裂缝真实落在面具实体上并有断面/错位/阴影，不以皮肤裂纹或涂画红线代替。若要求上下拼接面具露出双眼与局部皮肤，明确上额板、下颌板及其连接，保留中间开放的皮肤带与两只真实可见的眼睛；拒绝眼睛被罩住、两枚面具LED假眼，及多视图拼图冒充单幅角色全身。
- 若用户要求上下拼接面具“只露出双眼”，与露肤带版本区分：上额板和下颌板在眼位开两个紧贴真实眼球的小孔，眉、鼻梁、双颊、颈及身体其他皮肤均遮严；无露肤处就不要强行加默认皮肤大理石纹。核对每张面具的实体裂缝与上下两件接合；参考图若是骷髅面具，避免复制鼻洞、牙齿、颧骨眼窝与兜帽。八张不能只换甲片：先拉开长袍、宽腰环、巨型护臂、单侧肩甲等整体剪影，再逐张审图。
- 若用户明确要求重新设计五官，图一只留作面部特征/材质线索；重做眼眶、鼻唇与颧骨组合，不照搬原图的妆容、裂纹位置或拍摄角度。若指定“满红色瞳孔、没有眼白”，让整个可见眼球都呈红色，而不只是红色虹膜；该要求覆盖闭眼或普通红眼默认。
- 若用户指定某张图只供外形参考，优先提取轮廓和姿态，不复制该图的服装、面具与场景；若指定四条长肢体着地，逐张检查是否恰有两前肢和两后肢、四个末端各自触地，特别排除背后多出的支撑肢体。
- 若明确要求巨型壮汉 Necroid “没有脖子，头直接与身体连接”，不要仅缩短脖子：正面构建肩峰高于头、头骨基部与胸骨/肩甲连续融合且无喉部、颈柱、领环或悬空缝隙；保持巨大的胸肩、粗壮长臂和承重腿。先用全组缩略图筛掉瘦长人形，再在原尺寸检查头肩接合；不能以面具或兜帽遮住可见的颈柱来冒充无颈。该轮“图一只供外形”优先于本 skill 的图一面部默认职责。

- 若用户指定图二只作“手部和手臂钳类”参考，图二的环饰、面具、衣袍和场景不转移。正面为左右两条手臂各设计从肘/前臂连续生长的功能性双颚钳：固定/活动颚、对向弧度、转轴与可闭合的开口可追踪；不要把单根镰刀、普通五指爪、手持武器或背后附肢充当钳手。为八张先分配不同钳的宽窄、颚齿、开口方向及左右不对称性，并在全身图原尺寸核对两只钳和完整足部；同时保持图一指定的壮汉体量，不能为了细长剪刀钳把整个人体生成瘦长型。

- 若图一是蜘蛛/多附肢机甲而用户要求“更纤细的潜行者外形”，将图一的附肢语言转译为少量贴背、可折叠的细探测/稳定构件，保持明确的两条手臂与两条完整承重腿；不要把展台、六只假眼或多根落地蜘蛛腿照搬。先在缩略图核对肩、髋、大腿的宽度与装备体量，过宽的胸甲/腿甲即使腰细也不算潜行者；在原尺寸复查两只真实眼睛、全部足部以及参考二的剑、双长尾和头角是否错误漏入。

## 下半脸机械接口变体

- 若用户指定参考图一下半脸的机械接口与插管，不能用普通布罩或无管的面甲代替。为每张设计清楚的鼻口遮挡板、面部插孔/固定环、实际插入的管线及其颈部或胸前接收端；在放大的头部图中逐条追踪连接，不把红色刻线或悬空触须当插管。
- 图一若鼻口被接口遮住，不擅自生成可见鼻唇。参考其**功能结构**但重新设计端口数量、布局、金属材质与管线走向，避免照搬同一只中置罐体、两根对称软管、兜帽和额头标记；八张的头骨与面部接口应有差异。

## 蜥蜴人及尾部变体

- 若本轮要求蜥蜴人，图一仅提供允许借鉴的鳞片与眼部语言；正面建立新的爬行动物吻部、鼻孔、口裂和骨相，不照搬人脸。眼睛可见且要求竖瞳时，在原尺寸检查红色虹膜内是否有清晰的黑色纵向瞳孔；全身缩略图不能证明瞳孔达标。
- 若要求长蜥蜴拖尾与一排倒刺，先锁定**一条**尾巴，从下背/骨盆根部经连续尾身到完整尾尖，预留画面侧边空间；倒刺只沿尾背连续一排并向后倾斜。逐张查根部、尾尖是否被裁切，以及参考图的多条触手是否漏入。

## 触手下身女怪物变体

- 若图一仅供外形参考，而本轮指定细长上扬的头颈、沿头部前缘延伸的齿列巨口、枯瘦双臂、破袍、手持带钩长柄倒钩武器和下半身粗大盘绕触手，逐项锁定这些结构；图二及后续图只供机甲材质与红色光效，不转移其真人脸、双腿、刀剑或额外背部触手。
- 每张从同一个腰/骨盆根部追踪数条粗触手至可见末端，确认袍下没有隐藏的大腿、膝盖和靴足；沿头部前缘检查巨口和尖齿真实连贯，不能把身体或胸前的裂纹当作头部齿口。沿持械手追踪握持接点、完整杆身、钩头及倒钩，拒绝悬空器具或普通剑/镰刀替代。
- 八张先分配不同的头颈弧线、肩袍宽度、手臂姿态、触手粗细与盘绕拓扑；在缩略图与原尺寸分别核对全景、端点和彼此差异。

## 执行与验收

1. 检查**本轮**所有参考图并分别记录面部与服装/机甲的职责；新消息对具体部位的要求覆盖上述默认值。
2. 为八张先分配不同的整体轮廓、头肩胸腰腿结构、服装与机甲连接方式和可见面部识别点，再用 ChatGPT/OpenAI 图像生成工具各自从原参考图独立生成；不用上一张生成图级联到下一张，不调用 Claude 或 Higgsfield。
3. 对每张核对真人脸质感、只依据图一可见五官、面部差异、红眼条件、局部裂纹、黑红主次、完整正面全身、白色无缝棚拍及 2:3。检查八张之间是否真正独立设计，不能只靠文件哈希证明。
4. 核对八个独立文件能打开、数量与比例正确，再在聊天中逐张交付，不以拼图代替。无法确认的视觉细节要如实说明。
