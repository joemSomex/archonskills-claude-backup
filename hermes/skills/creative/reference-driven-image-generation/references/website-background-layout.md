# Website background layout and variant design

- For a multi-image environment batch, assign distinct shot slots before dispatch: change camera height and direction, near/mid/far focal subject, and shot scale (wide bay, side aisle, high angle, low angle, machinery detail) while keeping the reference-defined architecture and lighting.
- Map the UI overlay to a measured quiet region before prompting. If it sits on an inactive central display, require a flat-on rectangle with straight edges, dark uninterrupted glass, no reflection or bright motif inside, and foreground furniture below rather than across it. Lock screen bounds and visual calm separately from the room; inspect both at delivery size so a cinematic room does not fail as a usable player plate.
- When an exterior reference controls only sky and time of day, import its low sun and cloud color through a bounded window, excluding its tower or structure; otherwise salient exterior architecture leaks indoors.
- For fixed-camera batches, reserve different dominant room silhouettes before dispatch (low barrel vault, high faceted vault, radial rotunda, deep entrance aperture, wide shallow room). Vary seating connection graph, pit-to-frame scale, alcove depth and foreground floor while preserving the measured overlay region and window roles. On more variants, compare a labeled contact sheet within the new slate and against the accepted image; replace near-duplicates with a different ceiling/aperture AND seating topology. Hashes, sun positions, adjectives or minor furniture shifts are insufficient when a strong room reference pulls frames to the same composition.
