# Animated style calibration for photo-based references

1. Inspect the current source and label its identity/costume/prop authority separately from every style reference. Preserve covered eyes, hair color and length, handedness, asymmetric armor, mounted equipment and visible held props across all views; a generic style face has no authority over those features. Magnify the ORIGINAL image before counting tiny repeated identity marks, such as mask sensors; if the count is uncertain, inspect a tight crop or its color components, then use that enlarged original crop as an identity-only additional reference for failed slots. Verify the count again in both the full-body view and close portrait at native size, because a mistaken count in the prompt or a tiny omitted mark can propagate through the whole batch.
2. Calibrate one output before batching. At thumbnail and native size, inspect both exposed face and costume surfaces: deliberately designed cheek/brow/nose planes, grouped hair, matte brush-shaped armor and cloth values must replace photographic microtexture and specular shine. A painted backdrop or surface noise over a near-photo figure is not a successful animation conversion.
3. When the style swatch as `image_url` changes the source's shape, material colors, or anatomical details, keep the ORIGINAL source as `image_url` and pass the swatch as a style-only `reference_image_urls` input; inspect one sheet for both stronger brush planes and preserved identity before batching. If a material-only swatch still anchors the generator to photorealistic figures, generate an identity-dissimilar generic portrait with unmistakable mature hand-painted facial planes. Use it as *style only*, with the current source as the sole identity/design authority; explicitly forbid importing the style portrait's hair, eye count/color, face, clothing, body type or palette. Inspect one corrected output for both actual painted anatomy and source fidelity before rerendering the batch.
4. Keep each variation anchored to the untouched current source, never a preceding output. Verify true dorsal versus front construction, full heads/feet, exact attached versus held equipment in both full-body views, and a matching large portrait. Reject a shortened back-view prop, newly visible covered eye, mirrored asymmetry, or near-duplicate style variants even when filenames and hashes differ.
5. Compare all final images side by side, then inspect suspect files at native size. Normalize minor output-dimension variation without cropping character pixels. If reasonable style-reference attempts still yield photo-retouches, report the style shortfall rather than counting them as finished animated interpretations.
