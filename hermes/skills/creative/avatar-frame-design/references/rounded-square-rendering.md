# Precise rounded-square avatar frames

Use when the brief specifies a square frame with a numerical border radius and a thin, transparent profile opening. Reference images may show circular frames: use their material, palette and structural motifs, not their geometry.

1. **Reserve distinct constructions and inspect source roles.** Assign supplied images to texture, lighting, palette, or detail roles; exclude text, logos and sample-sheet layout. Reserve several visibly different band topologies (continuous rail, twin openwork rails, corner clasps, negative-space notches, staggered plates, woven truss, filigree). If all assets use the same rounded-square envelope, make their fasteners, transparency rhythm, and material visibly different at avatar size; hashes or hue swaps alone are not evidence of distinct concepts.
2. **Generate material candidates independently when needed.** Request one front-on rounded-square border per image, four visibly straight sides, a large empty rounded-square opening, full exterior padding, and flat chroma green in the opening *and* outside the frame. Keep a square reference for shape; when another reference is a very tall frame or horizontal banner used only for material, supply a bounded crop of its metal/corner detail separately so its aspect ratio or incidental markings do not leak into the new silhouette. For oversized or alpha-bearing references rejected by an image provider, make bounded RGB copies for upload without altering the originals. Reject candidates that add text or fill the opening. A generated 14% corner radius is only an approximation: use the exact-geometry branch below when numerical precision is required, but do not impose it on an expressive generated frame when the user accepts visual rounding and prioritizes intact details; disclose the approximation.
3. **Construct the exact mask in output coordinates.** For a centered exterior box of side `S`, use `R = 0.14*S` when the user requests 14% border rounding; choose border width `w` small relative to `S` (roughly 2.5-4% is a useful starting range). The inner box is inset by `w` on every side and uses radius `R-w`, preserving parallel corners and a large profile well. Supersample or use an antialiased signed-distance rounded-rectangle mask. One useful signed distance at centered coordinates `(x,y)` is `q = abs((x,y))-(half_extent-R)` and `sd = length(max(q,0)) + min(max(q.x,q.y),0) - R`; keep pixels inside the exterior and outside the inner shape. Build the ornament geometry inside that envelope first: use a continuous narrow rail, then complete corner plates whose width tapers smoothly to the rail before a side midpoint. Keep sockets and fasteners set back from both alpha boundaries. Apply the *final* mask after material, shading and decorations so late layers cannot fill the aperture or alter the corner radius; do not use it to amputate an oversized generated plate.
4. **Transfer texture without inheriting generated geometry.** Fit the entire generated frame uniformly inside the padded canvas. Inspect the key's actual RGB range before extraction; for a nearly pure green key, a tested soft alpha is `clip((210 - (G-max(R,B)))/140, 0, 1)` on float RGB, but tune it to the render rather than treating the constants as universal. Infer contaminated antialiased-edge colors from nearby opaque metal pixels, and inpaint any remaining green-dominant visible pixels before clipping; a key-color fringe becomes conspicuous on both dark and light profile photos. Fill candidate-free portions of the geometric band with compatible shaded underlay; otherwise shifting a generated border onto the exact corners leaves blank seams. For a one-frame repair of cropped ornaments, render the complete geometry and transparent aperture first, request a material-and-lighting-only edit on a flat chroma-key composite, then apply only the edited RGB to the approved alpha. After each material edit, resize into final coordinates and measure how much of the designed alpha is covered by keyed foreground; inspect missed areas locally so a missing filament is not excused by high overall coverage. Measure the distance of extra foreground from the alpha boundary as well: a few pixels of edge halo are tolerable, but new metal crossing a slot or extending into the photo well is not. If a rail or ornament was omitted or a cutout filled, retry from the untouched chroma-key layout with a strict pixel-aligned surface-retouch prompt; omit a style-reference image when it keeps transplanting another frame's topology. Blend the accepted candidate's RGB by soft-key confidence onto the immutable designed alpha, using the layout's RGB where the candidate missed antialiased metal; this prevents green gaps without clipping newly invented shapes. Verify the output alpha is byte-identical to the designed mask, then inspect before/after at full resolution on dark and light mattes before offering to revise the rest of a collection. For a thinner follow-up based on existing transparent frames, remap each source's material across the new narrow band instead of simply cropping away its original inner rim: sample the source alpha along center-outward angular rays to find the first and last visible pixels, smooth those limits across adjacent rays, and sample source RGB at a proportional depth between them for each pixel of the output rounded-square band. Fill transparent source samples with nearby opaque metal color before mapping so openwork does not become black holes; then apply the exact geometric alpha mask. Give source corner clasps, crests, chains or fins only shallow localized extra band width where needed to remain legible; keep them inside the outer 14% envelope. If radial compression erases their identity at avatar size, redesign those details rather than treating different colors as unique concepts. For deliberate openwork, cut channels/notches *inside* the new band, not across the transparent photo area.
5. **Verify the delivered assets, not just source renders.** Decode every file and check requested dimensions/PNG/RGBA, exact count, unique hashes, zero alpha in the opening and surrounding canvas, nonzero thin side rails, corner shape, clean edge color, and padding. Check at least a side midpoint, a rounded corner and an interior point on dark and light mattes. For openwork, test that *some* pixels along each side remain rather than requiring one particular coordinate to be opaque. For a thinner follow-up, compute opaque-pixel coverage (`alpha > 127`) for both the previous and new slates and require an actual reduction, while inspecting at thumbnail size for retained detail. Compare visible border details, not a whole-canvas pixel-distance score dominated by transparent pixels. Keep contact sheets internal and attach each standalone asset separately.
