# Source Precedence and Corrections

## Precedence

Use the highest applicable source:

1. Latest explicit author correction
2. Canon-corrected derivative tied to that correction
3. Current supplied chapter or screenplay
4. Governing world bible or canon document
5. Older drafts, original extractions, and summaries

An original source remains immutable even when superseded. Label it provenance-only and point current readers toward the corrected derivative.

## Correction Decision Table

| Correction type | Preserve original? | Create derivative? | Update summaries/index? | Retire stale memory? |
|---|---:|---:|---:|---:|
| Title/name/capitalization | Yes | Yes when source text contains it | Yes | Yes |
| Character attribute | Yes | Yes for active prose/script | Yes | Yes |
| Draft metadata only | Yes | Yes if the internal label is wrong | Yes | Yes |
| World rule or ontology | Yes | Create corrected world-bible derivative or authoritative supplement | Yes | Yes |
| Planned future reveal | Yes | Usually no | Track as intentional open plotline | Replace any “continuity error” memory |
| Deliberately unwritten section | Yes | No | Mark pending; do not invent | Save the non-invention constraint |

## Safe Derivative Recipe

1. Copy from the preserved text extraction, never from a summary.
2. Add frontmatter identifying the original source, author correction, and governing status.
3. Use exact, bounded replacements. For names, use word boundaries. For pronouns or scene identity, isolate the scene first.
4. Verify required new text exists and stale text is absent from the corrected scope.
5. Confirm the original still contains its original wording and checksum.
6. Update the canon index to list both the original and corrected derivative, with the derivative marked current.

## Memory Correction Recipe

1. Recall the old fact and capture its fact ID.
2. Expire/forget every active stale duplicate with a correction reason.
3. Remember one corrected fact with project entity, provenance, and shared visibility when appropriate.
4. Recall the corrected term and verify the stale formulation no longer appears in active recall.

## Continuity Review Labels

- **Open:** No answer yet.
- **Partially answered:** Mechanism or consequence known, central question remains.
- **Resolved for audience:** Viewers know; characters may not.
- **Unresolved in-world:** Characters do not know, but author canon does.
- **Author-known, unrevealed:** World bible answers it; screen story has not.
- **Continuity decision:** Conflicting sources require author direction.
- **Intentional future reveal:** Author has confirmed the answer is being withheld.
