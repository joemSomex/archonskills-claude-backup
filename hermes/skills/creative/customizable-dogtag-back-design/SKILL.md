# Customizable Dog-Tag Back Design

## When to Use

Use when the user supplies a blank dog-tag photo plus layout, rank-emblem and customer-data references and requests one or more production-plausible personalized back designs.

Create production-plausible horizontal back engravings for a zinc-alloy dog-tag necklace from four role-specific references:

1. Image 1 is the blank dog-tag product and photographic authority.
2. Image 2 supplies layout or laser-mark styling only.
3. Image 3 is the replaceable rank emblem.
4. Image 4 supplies the customer values.

## Locked product rules

- Preserve image 1's tag geometry, raised rim, hole, connector, chain, zinc-alloy finish, scratches, perspective, background, crop, lighting and shadows.
- The tag and engraving read horizontally along the long edge.
- All lettering, the rank emblem and permitted framework use the same matte charcoal-black shallow recessed laser-mark appearance. Never render the emblem gold, bronze, yellow, luminous, raised or filled with polished metal merely because its source reference is gold.
- Treat image 2 as layout/style authority only. Do not copy its people, placeholder text, pseudo-writing, logos, fictional symbols or decorative noise.
- Convert the rank emblem to clean laser-safe monochrome linework while retaining its recognizable geometry. When revising line weight, change only the emblem footprint and preserve all other decoded pixels.

## Variable-data system

The design must survive different customer content without manual redesign:

- Use fixed regions for name, rank, ID number and the replaceable rank emblem.
- Use fixed label positions and fixed value starts, or fixed-width modular cells.
- Keep variable values left aligned rather than independently centering each line.
- Use a conservative condensed monospaced uppercase font size with reserved capacity for longer values.
- A name may occupy one or two lines only inside a preallocated name zone; rank and ID zones must not move.
- Typical field labels are `NAME:`, `RANK:` and `ID NO:`. Preserve the user's exact names, rank and digits.
- Omit `WELCOME` when the source form uses it as interface copy, and omit dropdown chevrons or other UI controls after a rank.

## Design restraint

- Structural divisions are allowed only when they establish fixed data zones: one vertical divider, a clipped-corner cell, a compact emblem frame or restrained corner ticks.
- Remove unnecessary horizontal separator lines and decorative grids when they do not improve variable-field alignment.
- Keep every stroke inside the raised rim and clear of chain hardware.
- Do not add extra words, symbols, emblems, watermarks or pseudo-text.

## Batch workflow

1. Inspect and role-label every supplied image by visible content, not upload order.
2. Generate exactly the number of independent PNG concepts requested, each from image 1 rather than from a prior output.
3. Vary the macro layout while retaining fixed customizable fields. Useful structures include emblem-left/data-right, data-left/emblem-right, top name band with lower rank/ID cells, and a two-line reserved name zone.
4. Check every output individually at native size.
5. Regenerate any output with misspelled data, malformed emblem geometry, gold coloring, copied reference text, clipping, unreadable type or decorative clutter.

## Verification

Before delivery, confirm for every PNG:

- Every required value is spelled exactly and every digit is correct.
- `WELCOME`, dropdown arrows and interface artifacts are absent when requested.
- The rank emblem is recognizable, monochrome black and plausibly laser engraved.
- Name, rank, ID and emblem occupy fixed replaceable zones that remain usable when content length changes.
- No unauthorized text, pseudo-text, logo or symbol appears.
- The tag remains horizontal and product details remain credible.
- Each requested output is an independent PNG file.
