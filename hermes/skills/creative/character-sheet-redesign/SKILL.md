# 角色表修改设计

## When to Use

当用户说“调用角色表修改设计skill”“修改角色表”“以图一为角色表基准”或“保留图一风格但变化大一些”时使用。它既能给出通用文字指令，也能在用户明确要求时生成修改后的角色表。

## Workflow

在执行前完整读取 `templates/通用指令.md`。将其中的角色图、后续参考图、具体调整要求和数量映射到当前请求；这是本 skill 的文字指令原版，不要默默收紧成仅增加纹路或小幅加厚。

1. 先识别所有实际提供的原图及用户指定的对象。图一仅作为重要文字信息调取和美术风格设计基准：提取应保留的原文、拼写及其部位对应关系，并参考笔触、材质表现、光影和整体美术语言；不得将图一的头盔、全身甲片造型、配色部位分布、比例、角色身份或角色表版式当作必须沿用的设计锁。后续图仅在用户指定的方向提供参考，不直接照搬其角色、原样装甲、武器、姿势、文字或水印。若附件顺序与可见内容冲突，按用户明确的角色分配核对原图，不猜测。
2. 全身机甲必须全面重新设计，不只是用户额外点名的装备：头盔/面罩、颈部、双肩、胸背、手臂/手部、腰胯、双腿/关节和靴足，以及相关承重、挂载与连接结构，都要有清楚可见的造型修改。改变整体轮廓、体量比例、甲片结构和部件组合，让全身从缩略图就与图一明显不同；不能只增加缝线、纹路、贴花、局部盾牌/火炮或轻微加厚。图一只提供文字与美术风格基准，不能把图二原角色直接套上。
3. 角色表需展示足以核对全身新机甲的正面、侧面、背面及必要特写；用户没有指定时可沿用这些视角，但不锁定图一原版排版或局部特写位置。所有视角和特写必须是同一套重新设计的头身、装甲、装备和结构，承重连接与活动关节合理，不能只在正面重做、侧背面沿用旧版，也不能生成数个彼此不一致的角色。
4. 从图一调取重要且可辨认的文字，逐字保留其拼写、大小写与标点；将它放在新机甲与原图相对应的部位，不强求像素级坐标。不得增添未经要求的文字、标志或水印。文字若无法准确生成，明确指出并建议后期逐字修正，不能把近似字形说成已精确保留。
5. 若用户要修改后的指令，直接输出按 `templates/通用指令.md` 填好的文字；若用户明确要求生成图像，使用允许的图像生成工具按指定数量生成独立角色表，并遵守用户适用的模型限制。未另给具体部件方向时，以全身机甲全面修改为默认设计方向；若缺少必须的原图才询问。生成后按当前要求检查全身每一主要部位、所有视角的一致性及重要文字，并核验数量和文件，诚实报告未达标项。
