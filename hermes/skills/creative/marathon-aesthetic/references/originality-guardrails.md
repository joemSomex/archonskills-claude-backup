# Originality guardrails

“Marathon Aesthetic” is an internal shorthand for broad design principles. A finished prompt or deliverable should stand on its own without naming or depending on the source property.

## Never transfer

- Logos, wordmarks, title treatments, slogans, fictional terminology, faction names, codes, or UI copy.
- Bugs, insects, mascots, running figures, character shells, costumes, props, weapons, equipment, poses, or silhouettes.
- Exact circular emblems, glyphs, icons, scans, diagrams, boot/reboot screens, status marks, and screen layouts.
- Exact palette values, proportions, or chapter-by-chapter palette sequence.
- Exact typefaces or letter constructions.
- Shot order, transition order, animation timing, or scene progression.

## Safe abstractions

- High contrast between negative space and compact information clusters.
- Asymmetric modular composition.
- Technical typography with large/small scale contrast.
- Subject-derived measurements, diagrams, and annotations.
- Interchange between physical render, wireframe, scan, and exploded view.
- Restrained scanlines, dithering, misregistration, and raster breakup.
- Limited functional palette architecture.
- Motion that reveals information through staged state changes.

## Derivation test

For every element, answer:

1. What does it communicate about the new subject?
2. Which project requirement produced it?
3. Would it still make sense if the source video had never existed?

If the third answer is no, redesign it.

## Similarity audit

Before delivery, compare:

- Silhouette
- Layout proportions
- Dominant symbol
- Palette balance
- Typography
- Naming
- Iconography
- Sequence order
- Motion timing

Change at least the elements that create recognition, not merely surface decoration. A new subject placed inside a copied interface is still a copy.

## Commercial work

For a public campaign, product, game, film, merchandise line, or website:

- Use original fonts or properly licensed typefaces.
- Use new project-owned symbols and labels.
- Document palette and component rationale.
- Keep source imagery out of production files.
- Have a human designer perform the final similarity review.
